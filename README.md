# Свадебное онлайн-приглашение (Flask + Python)

Одностраничный элегантный пригласительный сайт с обратным отсчётом, деталями
события, таймингом вечера и формой подтверждения присутствия (RSVP).

## Быстрый запуск локально

```bash
cd wedding-invite
pip install -r requirements.txt
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

## Как настроить под свою свадьбу

Все тексты, дата и место находятся в одном месте — словарь `EVENT`
в начале файла `app.py`. Поменяйте значения:

```python
EVENT = {
    "bride": "Айсанем",
    "groom": "Джамшид",
    "date_iso": "2026-08-27T18:00:00",
    ...
    "venue_name": "Ресторан «Сантини»",
    "map_url": "https://yandex.ru/maps/-/CTF5FH1P",
    "schedule": [ ... ],
}
```

Больше никакие файлы редактировать не нужно — шаблон подставит новые данные
автоматически (имена, дата, обратный отсчёт, тайминг, адрес).

## Ответы гостей (RSVP)

- Гости заполняют форму внизу страницы: имя, "Буду / Не смогу", число гостей,
  пожелание.
- Ответы сохраняются в файл `responses.json` рядом с `app.py`.
- Посмотреть список ответов: **http://127.0.0.1:5000/guests**

⚠️ Страница `/guests` не защищена паролем — не отправляйте на неё ссылку
гостям. Если нужно выложить сайт публично, стоит либо убрать эту страницу,
либо добавить простую защиту (например, `flask-httpauth`).

## Как выложить онлайн (чтобы гости открывали по ссылке)

Проще всего — бесплатные хостинги для Flask-приложений:

1. **Render.com** — залейте проект на GitHub, создайте Web Service,
   команда запуска: `gunicorn app:app` (добавьте `gunicorn` в requirements.txt).
2. **PythonAnywhere** — загрузите файлы, укажите `app.py` как WSGI-приложение.
3. **Railway.app / Fly.io** — аналогично, через подключение GitHub-репозитория.

После деплоя вы получите публичную ссылку вида `https://ваше-имя.onrender.com`,
которую можно разослать гостям (например, через Telegram).

## Структура проекта

```
wedding-invite/
├── app.py                 # Flask-сервер + все настройки события
├── requirements.txt
├── responses.json          # создаётся автоматически после первого RSVP
├── templates/
│   ├── index.html          # сама пригласительная
│   └── guests.html          # список ответивших гостей
└── static/
    ├── style.css            # оформление (кремовый + бордовый + золото)
    └── script.js            # обратный отсчёт, анимации, отправка формы
```
